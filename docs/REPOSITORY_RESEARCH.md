## ClosePaw target-file conclusions

The requested ClosePaw area was treated as an architectural deep dive rather than a code source. The verified behavior from the inspected turn/prompt/policy/session tree led to the following AL Agent decisions:

1. **`AgentSession` stays thin.** Long-running decision logic belongs to `AgentRuntime`/phase runners; Android `Service` is only lifecycle hosting.
2. **Turn state is explicit input/output.** Cross-turn state is held in `AgentState`, persisted by ports/repositories, not hidden mutable Activity/Service state.
3. **Perception is canonical and fresh.** A screen observation is captured before planning and again after actions for verification.
4. **Planning and execution are separate phases.** Tool selection/arbitration is not mixed with Android side effects.
5. **Prompt assembly is structured.** AL Agent uses typed prompt sections and version names instead of one monolithic mutable prompt string.
6. **Working memory is bounded.** Todo/scratchpad/context are first-class sections subject to compaction/token budgets.
7. **Loop warnings are evidence.** AL Agent records screen/tool fingerprints and hard-stops through execution budgets; it does not permit unbounded autonomous loops.
8. **Security gates precede side effects.** BLOCKED/CAUTIOUS app classification, permissions and approval policy are evaluated before a tool executes.

## License/provenance policy for AL Agent

- AL Agent source in this generated foundation is intended to be Apache-2.0 and **clean-room authored**.
- ChatterUI (AGPL-3.0) is architecture-only research; no source was copied or translated.
- Termux/Termux AI code is not embedded; AL Agent exposes only a clean-room optional provider/policy boundary for external execution.
- Permissive repositories are still not copied wholesale. Where an architectural pattern is common (provider adapter, repository, phase runner, MCP transport), AL Agent uses its own types/naming/contracts.
- Every future imported dependency must be recorded in the dependency/SBOM process and checked for license compatibility before release.
